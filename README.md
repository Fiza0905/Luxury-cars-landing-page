# Luxury Cars Landing Page

A modern automobile landing page showcasing the world's most expensive luxury cars. This project presents information about luxury and supercars with a clean article-style layout, navigation menu, search bar, car images, embedded videos, and car rental links.

## Project Overview

This project was created as a frontend development practice project inspired by an automobile magazine layout. It focuses on creating a structured and visually clean webpage using HTML, CSS, and Bootstrap.

The page contains a fixed navigation bar, search section, introduction, Top 10 luxury cars list, detailed car information, embedded YouTube videos, and car rental links.

## Features

- Fixed navigation header
- Automobile magazine-style navigation menu
- Search bar with focus effect
- Introduction section
- Top 10 luxury cars list
- Anchor links for quick navigation between cars
- Car images
- Detailed information about each car
- Embedded YouTube videos
- Car rental section
- Airport car rental links
- Hover effects
- Responsive Bootstrap grid structure
- Orange and black themed design

## Main Sections

### Header

A fixed navigation bar provides links to different automobile and travel-related sections.

### Search Section

The page includes a search field styled with an orange focus effect when the input is active.

### Introduction

The introduction explains the concept of luxury cars and presents information about the world's most expensive vehicles.

### Top 10 Section

A list of the Top 10 luxury cars is provided with anchor links that allow users to jump directly to individual car sections.

### Car Information

Each car has its own heading and description. The page also includes an image of the Rolls-Royce Boat Tail and embedded YouTube videos for several cars.
